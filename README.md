# Axis — by LS Brainstorm

A agenda inteligente que dá ritmo às ideias, roteiros e compromissos da LS Brainstorm.

## Rodando localmente

```bash
npm install
npm run dev
```

Crie um `.env.local` (veja `.env.local.example`) com as credenciais do Supabase.

## Stack

- Next.js (App Router)
- Supabase (Auth + Postgres + Realtime)
- Tailwind CSS
